# موقع نايل تكستايل — نسخة جاهزة للنشر

موقع تعريفي ثابت (Static Site) بدون الحاجة لسيرفر خلفي، مبني بـ HTML/CSS/JS فقط، ويدعم اللغة العربية بتخطيط RTL كامل.

## هيكل الملفات

```
nile-textile/
├── index.html                 # الصفحة الرئيسية (كل الأقسام المطلوبة)
├── pages/
│   ├── category-clothes.html  # صفحة قسم الملابس الجاهزة
│   ├── category-towels.html   # صفحة قسم الفوط
│   ├── category-robes.html    # صفحة قسم البرانص
│   └── category-fabrics.html  # صفحة قسم الأقمشة
├── admin/
│   └── admin.html             # لوحة تحكم محلية (localStorage) — غير مرتبطة بأي رابط عام بالموقع، تُفتح يدويًا عند الحاجة
├── css/style.css              # كل التنسيقات وهوية التصميم
├── js/
│   ├── data.js                # المنتجات والعملاء الافتراضية + دوال التخزين
│   ├── main.js                # سلوك عام: قائمة الموبايل، الأنيميشن، نموذج التواصل
│   ├── category.js            # عرض منتجات كل قسم
│   └── admin.js                # منطق لوحة التحكم
├── assets/
│   ├── logo-icon.png           # أيقونة الشعار (تظهر برأس كل صفحة)
│   ├── logo-full.png           # الشعار الكامل (يظهر أسفل كل صفحة)
│   └── favicon.png             # أيقونة المتصفح
└── README.md
```

## اللغة (عربي / إنجليزي)

الموقع ثنائي اللغة بالكامل. يوجد زر تبديل اللغة (English / العربية) في أعلى كل صفحة، يبدّل النصوص واتجاه الصفحة (RTL/LTR) فورًا، ويحفظ تفضيل الزائر في متصفحه بحيث يبقى مطبقًا عند التنقل بين الصفحات.

المنتجات والعملاء المضافون من لوحة التحكم يُحفظون تلقائيًا بنفس النص عربي/إنجليزي مبدئيًا (بدون ترجمة تلقائية)؛ لتخصيص الترجمة الإنجليزية لمنتج مُضاف يدويًا، عدّل الحقول `name_en` و `desc_en` و `tag_en` في `js/data.js`، أو أضف حقل ترجمة مستقل لاحقًا إذا رُبطت اللوحة بقاعدة بيانات حقيقية.

## الشعار والهوية البصرية

تم استخدام الشعار الرسمي المرفق (`NTI — Nile Textile Industries S.A.E.`) في:
- رأس كل صفحة (نسخة مصغّرة من علامة الشراع `assets/logo-icon.png`)
- أيقونة المتصفح / Favicon (`assets/favicon.png`)
- شريط أسفل كل صفحة قبل الفوتر مباشرة، بالشعار الكامل مع الاسم (`assets/logo-full.png`)

الألوان مستخرجة بالبكسل من ملف الشعار نفسه ومطبّقة على متغيرات التصميم في أعلى `css/style.css`:
- **الأزرق الكحلي (Navy)**: `#2E276D` — للخلفيات الداكنة والعناوين
- **الأزرق السماوي (Sky Blue)**: `#2490D0` — للتمييز، الأزرار، والروابط

لو حبيت تغيّر الشعار مستقبلًا، استبدل الملفات الثلاثة في `assets/` بنفس الأسماء، وعدّل قيم `--teal-deep` و `--dye-gold` في `css/style.css` لو تغيّرت الألوان.

## كيفية النشر

الموقع بالكامل ملفات ثابتة، لذلك يمكن نشره فورًا على أي من:

- **Netlify / Vercel**: اسحب مجلد `nile-textile` وأفلته في لوحة النشر (Drag & Drop)، أو اربطه بمستودع GitHub.
- **GitHub Pages**: ادفع المجلد إلى مستودع، وفعّل GitHub Pages من إعدادات المستودع.
- **أي استضافة تقليدية**: ارفع الملفات عبر FTP إلى مجلد `public_html` أو ما يعادله.

لا حاجة لأي أوامر بناء (build) أو تثبيت حزم — الموقع يعمل مباشرة بفتح `index.html`.

## نقاط تحتاج مراجعتك قبل الإطلاق

1. **بيانات التواصل**: رقم واتساب والبريد الإلكتروني وروابط السوشيال ميديا في قسم "تواصل معنا" هي بيانات نموذجية — عدّلها في `index.html`.
2. **نموذج التواصل**: حاليًا يفتح النموذج تطبيق البريد الافتراضي (mailto) برسالة معبأة مسبقًا. لإرسال الطلبات مباشرة إلى قاعدة بيانات أو بريد بدون فتح تطبيق خارجي، يلزم ربطه بخدمة مثل Formspree أو EmailJS أو سيرفر خاص بكم.
3. **لوحة التحكم (`admin/admin.html`)**: هذه نسخة عملية بدون قاعدة بيانات — التعديلات تُحفظ في `localStorage` الخاص بالمتصفح فقط، أي أنها لا تظهر لباقي الزوار ولا تُزامن بين الأجهزة. للنشر التجاري الفعلي (بحيث يشوف كل الزوار نفس المنتجات بعد التعديل)، يُنصح بربط الموقع بخدمة تخزين بسيطة (مثل Firebase / Supabase) أو لوحة تحكم خلفية بسيطة (API).
4. **الصور الحقيقية**: صور المنتجات حاليًا رسومات SVG تمثيلية (Placeholders) بنمط النسيج، يُفضّل استبدالها بصور فوتوغرافية فعلية للمنتجات.

## الأقسام المطبقة في الصفحة الرئيسية

- تعريف بالشركة
- مجالات التصنيع (نسيج تريكو، نسيج وبرة، صباغة، طباعة، تصنيع ملابس، تطريز)
- الدول المصدَّر إليها
- المنتجات (4 أقسام رئيسية، كل قسم يفتح صفحة مستقلة بها بطاقات منتجات قابلة للإضافة والتعديل)
- العملاء (قابل للإضافة والتعديل من لوحة التحكم)
- روابط السوشيال ميديا وقسم الطلبيات (نموذج تواصل)
